# Dra. Beatriz Rievers

Site editorial para odontologia estética, desenvolvido com Next.js e preparado para deploy na Vercel.

## Desenvolvimento

```bash
pnpm install
pnpm run dev:vercel
```

## Build de produção

```bash
pnpm run build:vercel
```

## Deploy na Vercel

Importe este repositório na Vercel. O arquivo `vercel.json` já define o framework, a instalação e o comando de build. A variável `VERCEL_PROJECT_PRODUCTION_URL` é usada automaticamente nos metadados sociais; opcionalmente, defina `NEXT_PUBLIC_SITE_URL` com o domínio definitivo.
